# Salesforce Agentforce

**AI agents that live inside Salesforce and act on CRM work.**

## What it actually does
Agentforce is Salesforce’s agent layer for customer-facing and internal CRM workflows. It is strongest when the data and process already live in Salesforce: support, lead handling, follow-ups, and case work.

## Key Features
- Deep Salesforce context
- CRM-native actions
- Support and sales workflow agents
- Enterprise admin and governance model

## Pricing
There is a lower-cost / Foundations entry point. Production use is typically usage- or conversation-based and can get expensive at scale.

## Strengths
- Best option if you already run the business on Salesforce
- Real actions inside the CRM, not a sidecar chatbot
- Stronger governance than most consumer agents

## Limitations
- Weak outside the Salesforce world
- Setup and cost can be heavy
- Not a general computer-use agent

## Best for
Companies already standardized on Salesforce.

## Skip if
You want a general-purpose agent for research, coding, or the open web.

## Final Verdict
A real agent product, but only if Salesforce is already the system of record. **Score: 7.7/10**
