# Convergence Proxy

**A general web agent that tries to finish browser jobs, not just answer questions about a page.**

## What it actually does
Proxy is Convergence’s computer-using web agent. You describe a multi-step internet task — research, booking, comparison, form-filling — and it operates a browser to work through it.

## Key Features
- General-purpose web / computer agent
- Multi-step browser workflows
- Consumer and business usage
- Built by a team with DeepMind roots

## Pricing
Freemium. Paid access has been sold on monthly plans; check current pricing before publishing an affiliate or price callout.

## Strengths
- Broader than a single-site scraper
- Aimed at real web tasks
- One of the clearer Operator-style alternatives

## Limitations
- Web UIs still break agents
- Product packaging has shifted over time
- Less of a persistent multi-bot workforce than Grok Bot

## Best for
People who want an agent that can operate websites end to end.

## Skip if
You need deep coding agents or CRM-native enterprise workflows.

## Final Verdict
A real browser agent in the general-purpose lane. Useful, still brittle like the rest of the category. **Score: 7.8/10**
