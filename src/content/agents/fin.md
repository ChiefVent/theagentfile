# Fin

**A support agent that is judged on resolutions, not chat volume.**

## What it actually does
Fin is Intercom’s customer-support agent. It answers customer questions, uses help-center and account context, and tries to close the issue without a human. You pay when a conversation is actually resolved.

## Key Features
- Support agent across Intercom and some external helpdesks
- Outcome-based pricing
- Knowledge-grounded answers
- Escalation to humans when needed

## Pricing
Fin is commonly billed at $0.99 per confirmed resolution. Intercom seat plans sit on top of that.

## Strengths
- Clear commercial model
- Built for high-volume support
- Strong product-support context inside Intercom

## Limitations
- Costs scale with ticket volume
- Best inside Intercom’s world
- Not a general computer-use agent

## Best for
Support teams that want an agent measured on closed issues.

## Skip if
You need a general research, coding, or desktop agent.

## Final Verdict
One of the more mature support agents, especially if you already run Intercom. **Score: 8.2/10**
