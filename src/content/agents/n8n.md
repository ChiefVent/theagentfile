# n8n

**A workflow engine with real agent nodes, not just another chat wrapper.**

## What it actually does
n8n is an automation platform that can run AI agents inside workflows. Technical teams use it to connect apps, add reasoning steps, and let an agent decide or act as part of a larger process. You can self-host it.

## Key Features
- Visual workflows plus agent nodes
- Huge integration catalog
- Self-host or cloud
- Good for custom internal agents

## Pricing
Self-hosted core is free. Cloud plans commonly start around €20/month.

## Strengths
- Control and portability
- Cheaper than many closed agent platforms
- Excellent for internal ops systems

## Limitations
- More technical than Lindy or Gumloop
- You still have to design the workflow well
- Not a full computer-use teammate

## Best for
Technical teams that want owned, customizable agent workflows.

## Skip if
You want a no-setup personal assistant.

## Final Verdict
One of the best options if you want agents inside a system you control. **Score: 8.1/10**
