# Decagon

**Support agents controlled by written operating procedures, not a black box.**

## What it actually does
Decagon is an enterprise customer-support agent platform. Teams define how the agent should behave, connect it to internal systems, and let it resolve tickets across chat, email, and now voice. There is also an assist layer for human reps.

## Key Features
- Agent operating procedures
- Chat, email, and voice
- Human-assist copilot
- Enterprise integrations and analytics

## Pricing
Enterprise. Reported shape is a platform fee plus per-conversation usage.

## Strengths
- Operators can change behavior in plain language
- Strong mid-market and enterprise traction
- Built for resolution, not just answers

## Limitations
- Not a consumer product
- Needs real ticket volume to make sense
- Setup is heavier than Intercom Fin

## Best for
Support orgs that want control over agent behavior and already have volume.

## Skip if
You want a personal productivity agent.

## Final Verdict
A strong enterprise support agent with more operator control than most. **Score: 8.0/10**
