# Grok Bot

**A real seat with a computer. Three weeks of production hours. Not a 9.**

## What it actually does
Grok Bot is xAI's product for persistent, named AI teammates. Each bot can use a cloud computer with a browser, filesystem, and terminal. Bots can hand work to each other instead of bouncing every step through a human. Teach-by-demonstration routines exist. Templates, shipped 28 Aug 2026, let you publish a blueprint that another account installs as a new independent copy.

Agent File uses three of those jobs as a **content pipeline**: Scout researches, Quill writes the Markdown, Forge files `src/content/agents/<slug>.md`. That is how *this site* uses the product. It is not the product review.

## Key Features
- Persistent named bots with memory and routines
- Cloud computer: browser, files, terminal
- Multi-bot handoff
- Templates: share instructions, selected memories, skills, first-party plugins

## Pricing
Bundled with SuperGrok Plus, Cursor Pro+, and Cursor Teams for full access; others get a limited trial. Heavy use burns a weekly allowance faster than the landing page implies. Confirm current plan gates on xAI before you budget it as a standalone seat.

## Strengths
- Form factor is a teammate, not a chat sidebar
- Browser reach into sites with no API
- Templates make a working job copyable without leaking secrets or custom MCP

## Limitations
- Shipped 11 Aug 2026. Track record is days, not quarters.
- Shared computer: one stuck VM can take every bot on the account down with it.
- Weekly quota and model routing are still settling.
- Templates exclude secrets, custom code, and custom MCP. Plugins must be reconnected.
- Do not leave payments, sends, or deletions unattended yet.

## Best for
People already on a plan that includes it, running one reversible workflow they will review.

## Skip if
You need a boring reliability record, published per-resolution economics, or an agent that has been in production for a year.

## Templates vs this file
A published template is a recipe. The recipient cooks their own copy. `loops` (Matt Palmer's outer-loop eng bot) is evidence the *product* is used for real work. It is not a second listing. The platform is the listing.

## Final Verdict
Architecture of a real seat. Too new for an 8 on this rubric. Templates do not change the score. **Score: 7.4/10**
